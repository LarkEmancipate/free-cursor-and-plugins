## 🧠 Prompt Lab

**Refactor.** Refactor the selected function to reduce cyclomatic complexity, add type hints, preserve behavior, and include a docstring.

**Test Generator.** Generate pytest / vitest tests for the selected code. Cover: happy path, edge cases, error handling. Mock external calls.

**Bug Hunter.** Analyze the selected code for bugs: race conditions, off-by-one errors, null safety, resource leaks. Return a patch.

**Doc Writer.** Write a concise README section for the selected module: purpose, usage example, API reference, common pitfalls.

**Perf Optimizer.** Optimize the selected loop for time complexity. Show before/after Big-O. Suggest data structure changes.

**Security Review.** Scan for OWASP Top 10 issues. Flag injection, XSS, CSRF, insecure deserialization. Provide remediations.

## 🛠️ Troubleshooting

|--------------|---------------|
| **AI not responding** | Check API key / switch model |
| **Indexing stuck** | Clear the Cursor index cache |
| **Extension crash** | Roll back to previous version |

| **Login loop** | Clear cookies and retry |
| **Duplicate shortcuts** | Reset keybindings to default |
| **Slow AI on Wi-Fi** | Switch to wired or 5 GHz |
| **Missing autocomplete** | Enable inline suggestions in settings |
